Task

Explain the difference between a hub and a switch

10 key points · lesson 8 “Hubs, switches, routers”

Student’s answer

A hub is a simple device that connects computers in one network. When a hub gets data, it sends it to every port, so all computers receive it even if the data is not for them. This makes the network slower and less secure.

A switch is smarter. It learns the MAC address of each computer and keeps a table. When data arrives, the switch sends it only to the port where the right computer is. Because of this there are fewer collisions, and many computers can talk at the same time (full duplex).

Today almost nobody buys hubs. In our classroom Room 2 uses a 24-port switch.
